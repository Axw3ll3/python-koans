# 26 — Repetition

> Det räcker inte att ha löst koanerna — du måste kunna använda rätt kunskap i rätt läge utan att kategorin är given.

## Det här tränar du

Den här modulen blandar koaner från de 25 tidigare modulerna utan att ange vilket koncept som testas. Du tränar förmågan att:

- Identifiera *vilken* Python-mekanism som är relevant
- Tillämpa kunskapen utan att kategorin är given
- Minnas och använda begrepp från tidigare moduler

## Komma igång

```bash
uv run pytest koans/26-repetition/ -x --tb=short
```

Det finns inga sektionsrubriker som avslöjar ämnet. Läs docstringen noga — den är din enda ledtråd.

## Om du fastnar

- Läs docstringen noga och identifiera vilket beteende som undersöks
- Om du inte minns — gå tillbaka till den relevanta modulens README och koaner
- Testa i Python-tolken med variationer för att bygga en mental modell

## Kan du förklara det?

När du är klar med modulen: välj fem valfria koaner från fem olika moduler och förklara mekanismen bakom varje svar — utan att titta på koanerna.
